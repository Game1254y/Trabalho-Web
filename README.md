# Bem Estar Fitness

## Sobre o projeto

O Bem Estar Fitness é um projeto desenvolvido em HTML5 e CSS3 para apresentar uma academia localizada em Três Lagoas – MS. O site divulga a estrutura da academia, os treinos oferecidos, os planos, os horários de funcionamento e as informações de contato.

## Tecnologias utilizadas

- HTML5: estruturação do conteúdo da página.
- CSS3: estilização, cores, layout e aparência visual do site.

## Funcionalidades

- Sobre: apresentação da academia e de sua estrutura.
- Treinos: divulgação das aulas de Jiu-Jitsu.
- Informações: contato por WhatsApp e Instagram.
- Horários: tabela de funcionamento de segunda a sexta-feira.
- Planos: seção para apresentação dos planos da academia.
- Navegação: links para acessar as diferentes seções da página.

## Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Verifique se os arquivos HTML, CSS e as imagens estão nos caminhos corretos.
4. Abra o arquivo `index.html` em um navegador.

## Objetivo acadêmico

O objetivo deste projeto é aplicar os conhecimentos fundamentais de desenvolvimento web, utilizando HTML para estruturar o conteúdo e CSS para personalizar a aparência de uma página.
